## 🚀 Projeto em destaque

### 🔵 SERVIX

**Marketplace inteligente de serviços locais**

O **SERVIX** é um projeto acadêmico desenvolvido com a proposta de conectar **clientes e profissionais de serviços locais**.

A plataforma busca facilitar a procura por profissionais, permitindo que usuários encontrem serviços, visualizem avaliações, solicitem orçamentos e realizem contratações.

**Tecnologias estudadas no projeto:**

`HTML` `CSS` `JavaScript` `PHP` `MySQL` `AJAX` `JSON`

> 💡 Um dos projetos que estou utilizando para colocar em prática meus conhecimentos de desenvolvimento web.
